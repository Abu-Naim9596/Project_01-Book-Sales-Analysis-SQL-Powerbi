<h2 id="project-overview">📝 Project Overview</h2>
This project demonstrates a full-cycle data analysis workflow. I designed a relational database in **PostgreSQL** to manage bookstore operations and connected it to **Power BI** to visualize global sales trends, genre performance, and customer behavior.

<h2 id="key-features">🚀 Key Features</h2>

* **Database Schema**: Created structured tables for `Books`, `Customers`, and `Orders` with defined primary and foreign key relationships.
* **Data Integration**: Managed automated data loading from CSV sources into the SQL environment using `COPY` commands.
* **Interactive Visualization**: Built a dashboard tracking $2.60M in total sales and 500 transactions across multiple countries.

<h2 id="tools-used">🛠️ Tools Used</h2>

* **SQL (PostgreSQL)**: Used for data modeling, schema creation, and complex analytical querying.
* **Power BI**: Utilized for data visualization and building an interactive business dashboard.
* **Data Processing:** CSV Import/Export.

<h2 id="sql-analysis">🔍 SQL Analysis Portfolio</h2>
I completed the following 9 business intelligence objectives using advanced SQL techniques:

1. **Genre Volume**: Retrieve the total number of books sold for each genre.
2. **Targeted Averages**: Find the average price of books in the "Fantasy" genre.
3. **Customer Loyalty**: List customers who have placed at least 2 orders.
4. **Popularity Metrics**: Find the most frequently ordered book.
5. **Premium Inventory**: Show the top 3 most expensive books of 'Fantasy' Genre.
6. **Author Performance**: Retrieve the total quantity of books sold by each author.
7. **Geographic Sales**: List the cities where customers who spent over $30 are located.
8. **Top Spenders**: Find the customer who spent the most on orders.
9. **Inventory Reconciliation**: Calculate the stock remaining after fulfilling all orders using `COALESCE`.
